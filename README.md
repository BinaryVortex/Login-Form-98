# Login Form

Login Form Built Using HTML, CSS and JavaScript.

![Login Form Screenshot](./Screenshot%202024-08-07%20075414.png)

## Overview

This is a simple, responsive login form built with plain HTML, CSS, and a bit of JavaScript for basic validation and interactive effects. It's intended as a learning / demo project to showcase layout, styling, and small UX touches.

## Features

- Clean, modern form layout
- Client-side validation (simple required-field checks)
- Responsive styling for different screen sizes
- Easy to customize (colors, fonts, layout)

## Demo / Preview

To run the project locally:

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Login-Form-98.git

2. Open `index.html` in your browser (double-click or use Live Server in your editor).

## Files

- `index.html` — markup for the login form
- `style.css` — styling and responsive rules
- `Screenshot 2024-08-07 075414.png` — screenshot shown above

## Customize

- Edit `style.css` to change colors, spacing, and typography
- Add more JavaScript for authentication, animations, or form handling

## Notes

This project is a frontend-only example and does not include any server-side authentication. Do not use it as-is for production authentication without adding secure backend handling.
